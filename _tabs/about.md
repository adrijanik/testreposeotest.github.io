# Cześć 👋

Mam na imię [Twoje Imię] i tworzę ten blog, aby dzielić się swoją drogą w świecie technologii, programowania i internetu.

Interesuję się głównie:

- web developmentem,
- AI i nowymi technologiami,
- tworzeniem projektów online,
- oraz budowaniem rzeczy, które są szybkie, proste i użyteczne.

Ten blog powstał jako miejsce do publikowania poradników, eksperymentów i notatek z nauki. Znajdziesz tutaj wpisy o Jekyllu, GitHub Pages, frontendzie i różnych technicznych ciekawostkach.

Poza kodowaniem lubię poznawać nowe narzędzia, upraszczać workflow i testować pomysły „just for fun”.

Dzięki za odwiedziny 🚀
